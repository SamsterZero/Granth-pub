# Granthalay Publisher Documentation & Policy Center

Welcome to the Granthalay Publisher Dashboard (`granth-pub`) policy and specification documentation.

This suite establishes the governance, privacy, security, and commercial rules that uphold the privacy-first integrity of the Granthalay ecosystem while enabling publishers to distribute digital books worldwide.

---

## Policy Index

| Document | Purpose & Scope |
| :--- | :--- |
| **[01. Data and Privacy Policy](01-data-and-privacy.md)** | Defines the boundary between publisher analytics and reader privacy, zero-logging of credentials, cookie session security, and data retention rules. |
| **[02. Publisher Agreement & Terms](02-publisher-agreement-and-terms.md)** | Outlines publisher eligibility, copyright ownership, non-exclusive platform distribution grants, content standards, and title withdrawal rules. |
| **[03. Commerce, Refunds & Taxation](03-commerce-refunds-and-tax.md)** | Covers multi-territory pricing models, payout schedules via Stripe Connect, digital goods refund limits, and marketplace facilitator tax obligations. |
| **[04. Security & Incident Response](04-security-and-incident-response.md)** | Details EPUB ingest threat modeling (Zip-slip, XXE, XSS defense), organization multi-tenant RBAC, and the security incident response runbook. |
